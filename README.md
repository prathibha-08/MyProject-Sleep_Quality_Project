💤 Sleep Quality Prediction System

A Machine Learning-based Sleep Quality Prediction System built using Python and Scikit-learn. This project predicts sleep quality as Good, Average, or Bad based on user health and lifestyle inputs such as sleep duration, stress level, and physical activity.

The system helps users understand how their daily habits impact their sleep health.

🚀 Features

Predicts sleep quality: Good / Average / Bad

Uses Machine Learning classification

User input-based prediction

Suggestion system based on sleep category

Simple and interactive interface

🧠 Technologies Used

Python

Pandas

Scikit-learn

Matplotlib (for visualization, if used)

Tkinter (if GUI version)

📊 How It Works

Collect user inputs (sleep hours, stress level, activity level, etc.).

Preprocess and prepare dataset.

Train classification model.

Predict sleep quality category:

✅ Good → Healthy lifestyle

⚠ Average → Needs improvement

❌ Bad → Poor sleep habits

Provide personalized suggestions.
